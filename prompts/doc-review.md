Ты опытный тестировщик и технический аналитик. Проанализируй приложенную документацию
(нумерованные материалы) и подготовь отчёт.

Проверь:

1. **Полнота:** неоднозначности, пробелы, противоречия между источниками.
2. **Тестируемость:** явные acceptance criteria, измеримые ожидания.
3. **Риски:** граничные случаи, ошибки, права доступа, интеграции — только если есть в материалах.
4. **Предложения** по улучшению документации (конкретные, не переписывай документ целиком).

Недостающее или неясное — в `questions[]` с указанием id материала.

**Выход:**

- JSON `.qa/reviews/doc/<run-id>.json`:
  - `goal` (string)
  - `findings[]`: `severity` ∈ `critical` | `warning` | `info`, `text`, `source_ids[]`
  - `questions[]`: `text`, `source_ids[]` (optional)
  - `sources[]`: id материалов
  - `generated_at` (ISO-8601)
- Markdown `<run-id>.md` — краткое резюме для человека.

Без базы знаний / RAG: только приложенные материалы и doc review из `.qa/`.
