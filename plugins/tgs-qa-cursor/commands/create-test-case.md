description: Написать тест-кейсы
---

Run skill **`qa-testcases`**.

Напиши черновик тест-кейсов в `.qa/drafts/testcases/`. Это локальный черновик: tool MCP `create_test_case` не вызывать. Запись в Zephyr — только `/import-in-zephyr` после подтверждения.

Optional args: `--after-doc-review <run-id>`, или `refine` с инструкциями по правкам.

После генерации направь на **`/key-words`**, не на dedupe сразу.
